```sql
ALTER TABLE orders ADD COLUMN IF NOT EXISTS decision TEXT;

```

`POST /api/v1/orders/{id}/evaluate` loads listing, bundle, ALUs, users, evidence, and chain
state, calls `run_checks`, persists `checks`/`decision`/`decided_at`, and returns the order.
