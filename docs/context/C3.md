## T3.1 — Real TinyFish proof

1. Ask the human for `TINYFISH_API_KEY`; put it only in `middleware/.env`.
2. Run `npm --prefix middleware run smoke:tinyfish`.
3. Run one real verification against a source URL the officer supplies (BhuNaksha or similar).
4. Create `docs/tinyfish-smoke.md`: date/time, URL, goal, run ID, status, latency, source URLs,
   screenshot path, and any CAPTCHA/block note. Never include the key.
5. If blocked, leave T3.1 `[]` and mark `**BLOCKED:**`; continue T3.2/T3.3 with mocked tests.

**Done:** a real `COMPLETE` event and at least one real source URL are documented.

## T3.3 — Review queue

`evidence_sheets`. Routes per contract:
